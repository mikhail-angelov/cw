Настройки

Для просмотра балансов ничего вводить не нужно. Чтобы отправлять или обменивать токены, добавьте свой приватный ключ либо создайте новый кошелёк и придумайте пароль платежа от 12 символов. Это новый пароль приложения: он шифрует ключ, вводится вручную при каждой операции и не восстанавливается.

Добавить ключ подписи

Введите приватный ключ выбранного кошелька (0x…). Он нужен только для отправки и обмена и хранится зашифрованным в macOS Keychain. Никому не сообщайте ключ и пароль.

Импорт из cwg

Только если у вас есть wallet_key из cwg: введите старый пароль cwg, затем придумайте новый пароль для этого приложения.

Создать кошелёк

Создаётся новый ключ и новые адреса Ethereum и TRON. Приложение покажет ключ один раз для резервной копии. Сохраните его вне приложения.

Сохраните резервную копию

Без резервной копии ключ нельзя восстановить после потери Keychain.

Защитить старый ключ

Личный RPC (необязательно)

Приложение работает через публичный Ethereum RPC без настройки. Если нужен личный сервер, создайте проект Ethereum Mainnet на infura.io и вставьте его Project ID. Нужен именно ID, не URL и не пароль кошелька.
